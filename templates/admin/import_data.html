Import Kiosk Data (JSON)

Upload a JSON file from your kiosk SD card containing health records with patient information.

JSON format: Date, Time, FirstName, LastName, Age, Gender, BloodPressure, HeartRate_BPM, OxygenSaturation_pct, BodyTemp_C, Weight_kg, Height_cm, BMI

Kiosk JSON Format

Single Record Format:

{
  "A": "Date",
  "B": "Time",
  "C": "FirstName",
  "D": "LastName",
  "E": "Age",
  "F": "Gender",
  "G": "BloodPressure",
  "H": "HeartRate_BPM",
  "I": "OxygenSaturation_pct",
  "J": "BodyTemp_C",
  "K": "Weight_kg",
  "L": "Height_cm",
  "M": "BMI"
}
